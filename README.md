# code-harness-vitals

This repository is archived. The gates live in
[`qol-mini`](https://github.com/ltruchot/qol-mini-4-ai-tui), as the `vitals` command:

```bash
npx qol-mini vitals .            # every gate
npx qol-mini vitals agents-md .  # one gate
npx qol-mini vitals skills . --repo-only
```
